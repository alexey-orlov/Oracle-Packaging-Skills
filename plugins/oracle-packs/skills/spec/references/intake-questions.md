# Intake questions — moved to the cards

The questions the owner is asked before any research now live on three cards, and are loaded only at that step:

- `cards/intake-a.md` — where the raw inputs are, which delivered case the pack starts from, whether an earlier packaging attempt exists.
- `cards/intake-b.md` — the roadmap item, the industries, which artifacts are wanted, who owns the pack.
- `cards/intake-c.md` — what may be named and to whom, which figures are cleared, the proof's length and price, what stays internal.

Each card carries its own questions, defaults and checks. How a question is put is in `cards/owner-language.md`.

One question the demo skill asks, not this one: the sources for the walkthrough — a video, screenshots, a written overview, or a screen-by-screen description. `/oracle-packs-web:demo` refuses to start without one, because a walkthrough invented from the brief would not match the product.
