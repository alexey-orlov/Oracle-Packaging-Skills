# Sign-off flow — moved to the cards

The pack is no longer confirmed part by part through eleven cards. It is settled in two moves, each with its own card, loaded only at its step:

- **The story** (`cards/story.md`) — name, one-liner, problem, solution and who buys it together, as 2–3 complete candidates in one comparison table, one widget, one pick.
- **Everything else** (`cards/industries.md`, `capabilities.md`, `workflow.md`, `architecture.md`, `oracle-products.md`, `metrics.md`, `packages.md`) — drafted in one pass with no questions, then checked by a fresh-context reviewer against each card's own checks.
- **The whole brief** (`cards/brief.md`) — one table, one gate: confirm · change · stop, then the build starts.

Each card holds what its part must contain, the checks a draft must pass, and the spec keys it fills. How anything is put to the owner is in `cards/owner-language.md`; the long form is `shared/references/talking-to-the-owner.md`.
