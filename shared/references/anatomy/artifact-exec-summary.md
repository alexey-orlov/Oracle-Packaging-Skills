# The executive summary — one slide, in the host deck's style

Built to paste into someone else's deck, on that deck's own master, so it renumbers itself.

**Six blocks on one slide**, in a two-row, three-column arrangement:

| | | |
|---|---|---|
| **Use case** — the name, the one-liner as a subtitle, problem → solution compressed into one card, the vertical names on one sub-line | **Solution layers** — the four-rung vendor ladder | **Proof of value** — the three stats with their caveat footnote |
| **Service packages** — three compact tier rows: name · scope · price · duration | **Capabilities** — the areas and categories, as much of the tree as the panel holds | **Planned next steps** — three numbered items |

A footnote line runs along the bottom: the price footnote, the metric caveat where figures are printed (with none there is nothing to qualify, and it is dropped), and the divergence sentence — standing alone when it is a full sentence, run into "Pack scope differs…" only when a fragment. The contact block is the internal one.

**The components, in the form they take here.** Name → the slide title. One-liner → the use-case subtitle. Problem ↔ solution → one card, solution first, the problem as one trailing sentence. Verticals → names only, inside the use-case block. Capabilities → the bottom-middle panel, areas and categories only. Architecture → the solution-layers ladder (a stack, not a flow). Required products → the ladder's rungs. KPIs → the proof block, business metrics only, attributed per channel; not cleared for this channel, the panel stays an empty instance of its container, never half filled; cleared but with no figure yet, the strip names the metrics being measured under one "results to follow" line. Technical criteria are not KPIs here — they ride the PoV tier's scope as "Proof accepted when …". Packages → the tier strip. ICP, the workflow and optional products are absent by design.

**Standing rules.** One slide. No new visual language — the host deck's own shapes and colours, and its existing diagram rather than an invented one. The internal cut may carry package prices and named accounts where the brief allows, and says so in the notes.
